# Mission: AI Agent 开发

> 注：本使命由 AI 导师根据现有学习路线图和 20 小时计划推断整理，如有偏差请直接修改。

## Why
在 20 小时内掌握 AI agent 开发的核心原理，做到脱离框架手写 tool-use agent——为工作场景（如数据问答助手、知识库客服）独立开发实用 agent 打下地基。

## Success looks like
- 脱离任何框架，手写带错误处理和护栏的完整 agent loop
- 交付一个自己真实使用的迷你 agent（带 10 题评估集和 README）
- 能判断一个需求该用固定流程（workflow）还是自主决策（agent）

## Constraints
- 总时长 20 小时（10 次 × 2 小时），建议隔天一次、约 3–4 周完成
- TypeScript 基础（并行 TS 课程进行中），agent 零基础
- 使用 OpenAI 兼容 API（智谱 GLM / DeepSeek / Qwen 均可）
- 教学语言：中文，技术术语保留英文

## Out of scope（20 小时内不追）
- 框架深入学习、多 agent 编排、微调、部署运维——详见 [00_学习路线图.md](00_学习路线图.md) 的长期安排
